<details>
<summary>🔧 One-time setup to activate Stats / Trophies / Snake / Activity Graph above (click to expand)</summary>

All four widgets above are blank until you turn on **one** workflow in **your** `jayanithyan/jayanithyan` repo (create this repo if it doesn't exist yet — a repo with the exact same name as your username is what GitHub renders on your profile page). Everything below is generated inside your own repo by GitHub Actions and committed as a plain file, so nothing here depends on a third-party server staying up.

1. In that repo, create `.github/workflows/refresh-profile-widgets.yml` with:

```yaml
name: Refresh Profile Widgets

on:
  schedule:
    - cron: "0 0,12 * * *"   # twice a day
  workflow_dispatch:
  push:
    branches: [ main ]

permissions:
  contents: write

jobs:
  refresh:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4

      # 1) Profile details / stats / top-languages / productive-time cards
      #    -> generated + committed straight to "main" by the action itself
      - name: Generate GitHub summary cards
        uses: vn7n24fzkq/github-profile-summary-cards@release
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        with:
          USERNAME: jayanithyan
          BRANCH_NAME: "main"
          THEME: "tokyonight"
          ANIMATION: "fade"

      # 2) Trophies -> generate trophy.svg, then commit it to "main"
      - name: Generate trophy SVG
        uses: Erik-Donath/github-profile-trophy@feature/generate-svg
        with:
          username: jayanithyan
          output_path: trophy.svg
          token: ${{ secrets.GITHUB_TOKEN }}

      - name: Commit trophy.svg
        uses: stefanzweifel/git-auto-commit-action@v5
        with:
          commit_message: "chore: refresh GitHub trophies"
          file_pattern: trophy.svg

      # 3) Activity graph + contribution snake -> both pushed together to "output"
      - name: Generate activity graph
        uses: maurodesouza/github-readme-activity-graph-action@v1
        with:
          username: jayanithyan
          options: theme=tokyo-night&hide_border=true&area=true
          output_path: dist/activity-graph.svg
          token: ${{ secrets.GITHUB_TOKEN }}

      - name: Generate contribution snake
        uses: Platane/snk@v3
        with:
          github_user_name: jayanithyan
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark

      - name: Push activity graph + snake to "output" branch
        uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

2. Commit the file, then open the **Actions** tab → **Refresh Profile Widgets** → **Run workflow** to trigger it manually the first time.
3. Nothing else to configure — `permissions: contents: write` at the top lets the workflow's built-in token push for you, so there's no personal access token to create or paste anywhere.
4. After the run finishes (~1–2 minutes), it will have created a `profile-summary-card-output/` folder and `trophy.svg` on `main`, plus an `output` branch with `activity-graph.svg` and the two snake SVGs. All the images in this README will start rendering automatically — no link changes needed on your end.
5. It then re-runs on its own every 12 hours (and on every push to `main`), so the cards stay current without you doing anything further.

</details>
